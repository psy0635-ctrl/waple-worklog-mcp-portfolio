## 개요

tomorrow_plan, memo(및 activities, created_files)에 개행이 포함된 값이
들어오면, 기존 코드는 `f"- {text} [라벨]"`처럼 한 줄로 조립했다. text 자체에
"\n"이 들어 있으면 이 한 줄이 여러 줄로 쪼개져 출력되는데, "- " 접두어와
근거 라벨은 조립된 문자열의 맨 앞/맨 뒤에만 붙으므로 중간 줄은 접두어도
라벨도 없이 맨몸으로 남는다. tomorrow_plan은 글머리 기호만 깨지지만,
memo·activities는 라벨이 빠진 줄이 "Git에서 확인된 사실"처럼 보이게 되어
프로젝트 지침 6번(확인할 수 없는 작업을 사실처럼 쓰지 않는다)을 위반한다.

fix 47e38ba는 `_format_bullet_lines()` 헬퍼를 추가해 여러 줄 문자열을
줄 단위로 분해한 뒤, 각 줄마다 독립적으로 "- " 접두어와 근거 라벨을 붙이도록
수정했다. test c96de9a는 이 헬퍼와 호출부를 검증하는 회귀 테스트다.

    from server import _build_draft, _build_chat_draft

    PLAN = "tomorrow_plan 줄바꿈 버그 수정\n_format_bullet_lines 헬퍼 설계\n테스트 4케이스 추가"

    TODAY = "2026-07-30"

    def show(title, text):
        print("=" * 60)
        print(title)
        print("=" * 60)
        print(text)
        print()

    # [1] Claude Code 경로 — 인계 메모에 없던 지점

    # [2] 채팅 경로 — 이미 재현 확인된 지점 (대조군)

    # [3] 같은 패턴이 memo에도 있는지
