## 개요

기존 _REDISPLAY_INSTRUCTION은 "[Claude 표시 규칙 — 이 대괄호 문단은
사용자에게 보여주지 마세요]"로 시작해, 모델에게 이 안내 자체를 사용자에게
숨기라고 지시했다. 코드가 이 은닉을 강제하지 않으면서 모델의 준수만
기대하는 구조라 프롬프트 인젝션과 형태가 같았다
(docs/development-notes.md 16절 백로그, "은닉 지시를 출처가 드러나는
투명 포맷으로 전환").

수정 후에는 "[waple-worklog-mcp 서버가 삽입한 안내]"로 시작해 이 문단이
서버 자신이 삽입한 것임을 밝힌다. 기존 기능 3가지 — ①전문을 요약하지
말고 그대로 표시 ②수정 재호출 시 변경점 한두 줄 요약 후 전문 재표시
③등록 대상 전체 내용이라는 사실 고지 — 는 그대로 유지했다. 분량은
462자 → 285자로 줄었다.

    # 일회성 캡처 스크립트 (저장소에는 포함하지 않음)
    import asyncio
    import server

    async def main():
        result = await server.call_tool(
            "chat_tasklog",
            {
                "activities": ["_REDISPLAY_INSTRUCTION 출처 표시 개편"],
                "created_files": ["server.py", "test_connector.py"],
                "memo": "은닉 지시 제거, 출처 라벨 추가",
                "tomorrow_plan": "팀 레포 반영",
            },
        )
        print(result[0].text)

    asyncio.run(main())

`server.call_tool`을 직접 호출한다. 서버 프로세스 기동·네트워크 요청 없음.
"수정 전" 출력은 server.py를 커밋 `4664208` 상태로 되돌린 뒤
